# Copilot Fixtures

- `probe.py` experiments with GitHub and Copilot API requests.
- `device_code_response.json` captures the device-login response.
- `oauth_token_response.json` captures the GitHub OAuth response.
- `copilot_token_response.json` captures the Copilot token exchange response.
- `github_user_response.json` and `github_user_emails_response.json` cover GitHub identity lookup.
- `copilot_user_response.json`, `copilot_user_business_response.json`, and the `copilot_user_pro_plus*` files cover free, business, and Pro+ usage schemas.
