# Login Flow Tests

- Provider files (`antigravity.rs`, `claude.rs`, `codex.rs`, `copilot.rs`, `gemini.rs`, `kimi.rs`, `minimax.rs`, and `opencode_go.rs`) test provider login flows.
- `generic.rs` tests shared login behavior.
- `key_authentication.rs` and `key_authentication_cases.rs` test API-key flows and case coverage.
- `support.rs` provides test fixtures/helpers.
- `mod.rs` registers the test modules.
