# Documentation

- `spec.md` is the canonical as-built product and architecture specification.
- `graphify.md` contains graph navigation instructions; read it only for `/graphify` requests.
- `RTK.md` documents the local token-optimized command wrapper and is intentionally ignored by git.
- `todo.md` is the local development backlog and is intentionally ignored by git.
- `agents/` contains local agent-system metadata and is intentionally ignored by git.

Update `spec.md` when user-facing behavior or architecture changes.
